# UTM Links — meetsohaib.com

Ready-to-use tracking links. Paste the matching link wherever you share.
GA4 will show these under **Reports → Acquisition → Traffic acquisition** (session source / medium / campaign).

Conventions (all lowercase):
- `utm_source` = where it's shared (linkedin, facebook, whatsapp, email)
- `utm_medium` = the format (social, dm, group, chat, email)
- `utm_campaign` = `free_audit` (the goal: get a Free Growth Audit request)

### Tips
- **Posts** (public feed) → use `utm_medium=social`. **DMs / 1:1 messages** → use `utm_medium=dm` (LinkedIn) or `utm_medium=chat` (WhatsApp).
- Keep `utm_campaign=free_audit` the same everywhere so GA4 groups all audit traffic together.
- Want to compare specific posts? Add `&utm_content=postname` (e.g. `utm_content=referrals_post`) — optional.
- In GA4: **Reports → Acquisition → Traffic acquisition**, then set the primary dimension to *Session campaign* / *Session source-medium*.
